Uma rede fictícia de 10 clínicas-escola, de nov/2025 a out/2026. O Power Query lê a base que o Python padronizou; cada medida foi conferida contra o Python dentro do motor do Power BI. As telas abaixo são do Power BI Desktop.

Visão geral

Faturamento, consultas, faltas e espera; quem veio, quem faltou e quem desmarcou, mês a mês.

Todas as páginas

Clique numa página para ver em tela cheia.

O modelo por trás

Um modelo estrela: três tabelas de fatos ligadas às mesmas dimensões, com a chave da clínica criada no Power Query.

Fatos

Atendimentos (70.679 linhas, com taxa, motivo e espera na recepção), oferta de horários por dia e turno, e a fila de espera.

Dimensões

Calendário (com recesso e feriados), clínicas, pacientes (sem nome nem nascimento: LGPD), alunos com meta de horas e professores.

Power Query

Tipos lidos com a cultura en-US, só as colunas que o modelo declara, a chave da clínica e a mesclagem da fila com os atendimentos.

Quatro medidas que contam a história

As 36 medidas estão no arquivo, com descrição. Estas quatro mostram as decisões que mais aparecem numa entrevista.

Taxa de faltas

Cancelamento avisado fica de fora do denominador: o horário pôde ser remarcado. A falta é o horário perdido.

Taxa de faltas =
DIVIDE ( [Faltas], [Realizados] + [Faltas] )

Chamados em até 30 min

No DAX, BLANK < 30 é verdadeiro. Sem o NOT ISBLANK, quem não teve a chamada registrada entraria como “atendido rápido”.

Chamados em até 30 min =
DIVIDE (
    CALCULATE (
        COUNTROWS ( atendimentos ),
        KEEPFILTERS ( atendimentos[espera_recepcao_min] < 30 ),
        KEEPFILTERS ( NOT ISBLANK ( atendimentos[espera_recepcao_min] ) )
    ),
    COUNT ( atendimentos[espera_recepcao_min] )
)

Deixou de entrar com faltas

Cruza o fato com a dimensão de pacientes: só conta a taxa de quem pagaria. Isento e atendimento sem prontuário ficam de fora.

Deixou de entrar com faltas =
CALCULATE (
    SUM ( atendimentos[valor_tabela] ),
    atendimentos[situacao] = "Falta",
    pacientes[isento_taxa] = "Não"
)

Alunos na meta

O CALCULATE dentro do FILTER faz a transição de contexto: soma as horas de cada aluno da linha e compara com a meta proporcional dele.

Alunos na meta =
COUNTROWS (
    FILTER (
        alunos,
        NOT ISBLANK ( alunos[meta_ate_fim_dados] )
            && CALCULATE ( SUM ( atendimentos[horas_pratica] ) )
                >= alunos[meta_ate_fim_dados]
    )
)

Abrir no seu Power BI

O relatório está no formato de projeto (PBIP), em texto, versionado no GitHub e gerado por código.

No Power BI Desktop

  1. Baixe o repositório no GitHub (Code › Download ZIP).
  2. Abra powerbi/clinicas_escola.pbip.
  3. Em Transformar dados › Editar parâmetros, aponte PastaDados para a pasta data/tratado.
  4. Clique em Atualizar.
Ver no GitHub

Como os números foram conferidos

  1. Com o relatório aberto, o motor do Power BI roda numa porta local.
  2. O script scripts/conferir_powerbi.py se conecta a ela, atualiza os dados e roda consultas DAX.
  3. Cada resultado é comparado com o número calculado em Python. Se algum diverge, o script falha.
